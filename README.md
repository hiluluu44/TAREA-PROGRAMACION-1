# Control de Versiones — Proyecto de ejemplo

Este repositorio es un ejercicio para practicar control de versiones con Git y GitHub.

Contenido:
- Explicación breve sobre control de versiones y utilidades.
- Un programa de ejemplo en C++ (`main.cpp`).
- Uso de dos ramas: `main` y `dev`.
- Historial con al menos 3 commits por rama.

Instrucciones rápidas:
1. Crear el repositorio en GitHub (ej.: `control-versiones`).
2. Clonar o inicializar el repositorio localmente.
3. Seguir los comandos del archivo de instrucciones provisto para crear commits y ramas.
4. Hacer push de `main` y `dev` al remoto.
